# IAMSIAM · STUDIO

One content-creation tool, two layers, one PNG sequence with a built-in alpha
channel:

- **VU layer** — the IAMSIAM ASCII logo as audio-reactive VU meters. Every
  horizontal bar of the artwork reacts **side to side** to whatever audio you
  load.
- **INFO layer** — a deterministic typed-text layer: "ARTIST — TITLE" +
  details line (or a title screen), a curator strip, and a blinking cursor.

Each layer can be toggled on/off, so the studio also covers both single-layer
workflows — or run the original standalone tools, which are kept in the repo.

Everything runs in the browser from a single file. No install, no server, no
dependencies; fonts and logo are embedded, so it works fully offline.

## Quick start

1. Open `iamsiam-studio.html` in Chrome or Edge (Firefox/Safari work too, but
   only Chrome/Edge support exporting straight into a folder — others use ZIP).
2. Drop an audio file anywhere (or **LOAD AUDIO**). mp3 / wav / flac / ogg /
   m4a all work. No audio is fine too — the info layer runs on its own.
3. Fill in the track info, tweak the meters, press **space** to preview. The
   checkerboard behind the canvas is the transparency — not exported.
4. **EXPORT SEQUENCE → FOLDER** (or → ZIP).

## The timeline rule

Both layers are time-addressed and deterministic — the preview and the export
call the same render function, so what you see is exactly what renders, every
time.

- **Audio loaded** → the sequence is the audio range set in OUTPUT. The info
  layer types from the start of that range and holds with a blinking cursor.
- **No audio** → the sequence is the info tool's native shape: typing +
  **exactly one 1.0s blink cycle**. The exported `info.txt` names that loop
  segment — loop it in your editor to fill any slide duration; the seam is
  invisible.

## Layers

### VU
Bar layout is derived from the logo PNG's alpha channel at load time (61 bars /
28 rows for the bundled logo — any line-based transparent PNG works via
REPLACE PNG). Controls: grow direction (center/left/right), frequency bands
per row or overall loudness, idle width, gain, contrast, attack/release,
per-band auto-leveling, peak-hold ticks, tint, logo margin.

### INFO
Two modes — **track info** (rank, artist, title, free-text details) and
**title screen** (two word-wrapped paragraphs). Optional bottom strip with
`curator // list title` and `NN / NN` rank. Per-element colors with reset.
Typing rhythm is generated by a fixed formula, so re-renders are
byte-identical. Title mode has a **typing duration** field that uniformly
scales the timeline to land typing on an exact length (e.g. sync to a
voiceover) while preserving the rhythm.

## Output

- PNG sequence, straight (non-premultiplied) alpha (or a black background if
  selected), named `<prefix>00000.png`, … — always numbered from zero so
  sections import cleanly as image sequences.
- Default 1080×1350 (Instagram portrait) @ 30fps; size, fps (24/25/30/50/60),
  range and prefix in OUTPUT.
- The prefix auto-fills from what's enabled — `<audio-or-track>_vu_`,
  `..._info_`, `..._full_` — until you type your own; clear the field to
  re-enable auto-naming.
- Every export writes `<prefix>info.txt` beside the frames: layers, audio
  file and range, track text, frame counts, the loop segment (no-audio mode),
  and ready-to-paste ffmpeg lines.

### Turning the sequence into a video with alpha

```sh
# ProRes 4444 (Premiere / Final Cut / DaVinci)
ffmpeg -framerate 30 -i prefix_%05d.png -c:v prores_ks -profile:v 4444 -pix_fmt yuva444p10le out_alpha.mov

# VP9 WebM (web)
ffmpeg -framerate 30 -i prefix_%05d.png -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 24 out_alpha.webm
```

Or import the PNG sequence directly into After Effects / Premiere / Resolve —
the alpha comes with it.

## Files

- `iamsiam-studio.html` — **the merged tool** (both layers; logo + fonts embedded)
- `iamsiam-vu.html` — standalone VU layer (the original visualizer)
- `iamsiam-info.html` — standalone INFO layer (the original typed-text tool)
- `index.html` — redirect stub so the GitHub Pages root URL opens the studio
- `assets/IAMSIAM_ASCII.png` — the source ASCII logo
- `docs/VU_TOOL_TECHNICAL_NOTES.md` — how the VU engine works and why

The studio's single-layer output is verified byte-identical to the standalone
tools (deterministic rendering makes that testable), so sequences exported
from either stay interchangeable.
